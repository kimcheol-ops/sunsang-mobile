휴대폰 카메라로 찍으면 앱 주소가 열려요

안드로이드(갤럭시 등) — 홈 화면에 설치

  1. 위 QR을 휴대폰 카메라로 찍거나 주소를 크롬으로 열어요.
  2. 앱 첫 화면의 「📲 앱으로 설치 → 설치하기」를 누르거나, 크롬 오른쪽 위 ⋮ → 「앱 설치」(또는 「홈 화면에 추가」)를 눌러요.
  3. 홈 화면에 생긴 「관제 우주」 아이콘으로 열면 주소창 없이 앱처럼 열려요.
업데이트는 자동이에요. 한 번 열어 두면 게임·물때는 인터넷이 없어도 돼요. 삼성 인터넷은 메뉴 → 「현재 페이지 추가 → 홈 화면」.

아이폰

  1. 사파리로 주소를 열어요.
  2. 아래 공유 버튼(□↑) → 「홈 화면에 추가」를 눌러요.

안드로이드 설치 파일(APK)

PC에서 만든 APK 파일을 휴대폰으로 옮겨 설치할 수도 있어요. 이때는 휴대폰 설정에서 「출처를 알 수 없는 앱 설치 허용」을 본인이 직접 켜야 해요. 플레이 스토어에는 올리지 않아요(등록비 유료).
